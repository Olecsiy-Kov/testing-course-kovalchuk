# Тестування програмного забезпечення — наскрізний проєкт

**Виконавець:** Ковальчук Олексій В.  
**Група:** КНТІТ 63М

## Обраний застосунок

Навчальний вебзастосунок **«Система управління студентами»** — облік студентів і їхніх оцінок на факультеті. Має REST API та вебінтерфейс; ролі: адміністратор (деканат), викладач, студент. Застосунок веде записи студентів, приймає бали викладачів, автоматично переводить їх в оцінки ECTS і формує відомості успішності груп у PDF та XLSX.
