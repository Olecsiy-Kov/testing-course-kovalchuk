# Реєстр ризиків

**Шкала ймовірності:** 1 — малоймовірно (проста, стабільна логіка); 2 — можливо; 3 — дуже ймовірно (складна логіка, часті зміни, нова технологія).
**Шкала впливу:** 1 — незручність без втрати даних; 2 — порушення функції, є обхідний шлях; 3 — неправильні оцінки, втрата або витік даних, зупинка роботи.
**Рівень ризику** = ймовірність × вплив: 1–2 — низький, 3–4 — середній, 6–9 — високий.
